# Dr. Sazzadur Rahman Rumon - Official Website

This is a premium Apple-style fluid glass portfolio and smart chamber serial booking website for **Dr. Sazzadur Rahman Rumon** (MBBS [DMC], BCS [Health], CCD [BIRDEM], CMU [Ultra], M-Phil [Course], Lecturer at Shaheed Ziaur Rahman Medical College [SZMC], Bogura).

## 🚀 Features & Highlights

- **Apple Fluid Glass Design System**:
  - Translucent frosted glass layers with dynamic multi-color ambient mesh orbs (`backdrop-filter: blur(28px) saturate(190%)`).
  - Specular edge highlights, sheen hover micro-animations, and smooth spring curves.
  - Seamless Light Mode & Dark Mode toggle with persistent memory.
- **Zero Build Pipeline**: Built with pure HTML5, vanilla JavaScript, Tailwind CSS (via CDN), and Lucide Icons (via CDN).
- **100% Client-Side**: No Node.js, no `npm install`, no server dependencies.
- **Bilingual Experience**: Instant toggle between Bengali (বাংলা) and English (EN).
- **Real-Time Live Chamber Status**: Dynamic status badge automatically showing whether Chamber 1 or Chamber 2 is open today based on the day of the week.
- **Interactive Apple Health Screener**:
  - Live BMI & Diabetes Metabolic Risk screener with interactive sliders (Height, Weight, Blood Glucose).
  - Real-time classification gauge and clinical consultation guidance.
- **Smart Chamber Serial Assistant**:
  - **Direct Hotline Calling**: 1-tap call & 1-click copy with toast notification for:
    - **Chamber 1:** Oxygen Health Care (Gabtali, Bogura) — `01302-031077`
    - **Chamber 2:** Elite Diagnostic & Consultation Center (Bogura) — `01735 164 172`
  - **WhatsApp Serial Generator**: Auto-formats a structured appointment reservation and opens WhatsApp directly.
  - **Google Maps Integration**: 1-click directions to both chambers.
- **Clinical Services & Treatments**: In-depth treatment cards with symptoms, clinical approach, and 1-tap booking trigger.
- **Health Tips & Education**: Category filtering and live search for chronic care and seasonal prevention.
- **Physician Timeline & Bio**: Verified BMDC Registration, BCS Health Cadre credentials, and academic milestones.
- **Patient Stories & Reviews**: Authentic patient experiences and recovery stories.
- **Emergency Medical Advisory**: Apple glass advisory banner for critical emergency guidance.
- **Full View Responsive for PC & Mobile**:
  - Widescreen full-view desktop layout with floating pill island navigation.
  - Mobile-optimized view with an Apple iOS floating bottom dock for instant access on any smartphone.

## 🌐 Deploy to GitHub Pages (1-Click)

1. Push this repository to GitHub:
   ```bash
   git add .
   git commit -m "Apple fluid glass UI upgrade with full PC and phone view"
   git branch -M main
   git remote add origin https://github.com/<your-username>/<your-repo-name>.git
   git push -u origin main
   ```
2. Go to your repository on GitHub.
3. Click on **Settings** > **Pages**.
4. Under **Build and deployment**:
   - **Source**: Select `Deploy from a branch`
   - **Branch**: Select `main` and folder `/ (root)`
   - Click **Save**.
5. Your site is live at: `https://<your-username>.github.io/<your-repo-name>/`!
