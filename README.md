# Dr. Sazzadur Rahman Rumon - Official Website

This is a clean, standalone, static portfolio and chamber serial booking website for **Dr. Sazzadur Rahman Rumon** (MBBS, BCS Health, CCD Diabetes, Lecturer at Shaheed Ziaur Rahman Medical College, Bogura).

## 🚀 Features

- **Zero Build Pipeline**: Built with pure HTML5, vanilla JavaScript, Tailwind CSS (via CDN), and Lucide Icons (via CDN).
- **100% Client-Side**: No Node.js, no `npm install`, no server dependencies.
- **Bilingual Support**: Dynamic toggle between Bengali (বাংলা) and English (EN).
- **Interactive Chamber Booking**: Direct click-to-call hotlines and one-click copy number for:
  - **Chamber 1:** Oxygen Health Care (Gabtali, Bogura) — `01302-031077`
  - **Chamber 2:** Elite Diagnostic & Consultation Center (Bogura) — `01735 164 172`
- **Clinical Services & Treatments**: Detailed symptom profiles, expectations, and treatment duration.
- **Health Tips & Education**: Category filtering and live search for chronic care and seasonal prevention.
- **Physician Timeline & Bio**: Verified BMDC Registration (`A-84951`), BCS credentials, and academic milestones.
- **Mobile Optimized**: Responsive layout with a sticky bottom booking bar on scroll and floating WhatsApp helper.

## 🌐 Deploy to GitHub Pages (1-Click)

1. Push this repository to GitHub:
   ```bash
   git add .
   git commit -m "Standalone static website for GitHub Pages"
   git branch -M main
   git remote add origin https://github.com/<your-username>/<your-repo-name>.git
   git push -u origin main
   ```
2. Go to your repository on GitHub.
3. Click on **Settings** > **Pages**.
4. Under **Build and deployment**:
   - **Source**: Select `Deploy from a branch`
   - **Branch**: Select `main` and folder `/ (root)`
   - Click **Save**.
5. Your site is now live at: `https://<your-username>.github.io/<your-repo-name>/`!
